Pipeline Workflow Architecture

FreshChain implements a complete end-to-end production ML pipeline structured into decoupled modules:

  • 1. Data Ingestion Automated loading, deduplication & schema validation in ml/data_loader.py
  • 2. Visual EDA Distribution, class balance & correlation heatmaps in ml/eda.py
  • 3. Feature Engg StandardScaler + OneHotEncoder pipelines in ml/feature_engg.py
  • 4. Model Trainer Multi-model benchmark & serialization in ml/trainer.py
  • 5. Real-Time Inference Fast sub-millisecond serving via models/load.py
